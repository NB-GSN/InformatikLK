Das Prinzip bekommt einen Namen

Der Stack arbeitet nach dem Prinzip LIFO (Last In, First Out). Ein Wartezimmer braucht das umgekehrte Prinzip. Wie lautet die Abkürzung und wofür steht sie?

Merke: Stack und Queue im Vergleich

Stack (Stapel)Queue (Schlange)
PrinzipLIFO: Last In, First OutFIFO: First In, First Out
Hinzufügenpush(x): oben draufenqueue(x): hinten anstellen
Entfernenpop(): oberstes wegdequeue(): vorderstes weg
Nachsehentop(): oberstes Elementfront(): vorderstes Element

AlltagTellerstapel, Rückgängig-FunktionWartezimmer, Druckerwarteschlange, Supermarktkasse

Aufgabe 2.2✓ erledigt

Auftrag oder Anfrage?

Ein Auftrag verändert das Objekt (Rückgabetyp void), eine Anfrage liefert einen Wert und lässt das Objekt unverändert. Ordne zu.

MethodeArt
boolean isEmpty()
void enqueue(ContentType pContent)
void dequeue()
ContentType front()
Fachlich wichtig (Abi-Dokumentation): front() liefert bei leerer Schlange null. dequeue() bei leerer Schlange und enqueue(null) lassen die Schlange unverändert, es gibt also keinen Fehler.

Dokumentation

    
Die generische Klasse Queue<ContentType>

    
Objekte der generischen Klasse Queue (Warteschlange) verwalten beliebige Objekte vom Typ ContentType nach dem First-In-First-Out-Prinzip, d. h. das zuerst abgelegte Objekt wird als erstes wieder entnommen. Alle Methoden haben eine konstante Laufzeit, unabhängig von der Anzahl der verwalteten Objekte.

    
Konstruktor
Queue<ContentType>()
Eine leere Schlange wird erzeugt. Objekte, die in dieser Schlange verwaltet werden, müssen vom Typ ContentType sein.

    
Anfrage
boolean isEmpty()
Die Anfrage liefert den Wert true, wenn die Schlange keine Objekte enthält, sonst liefert sie den Wert false.

    
Auftrag
void enqueue(ContentType pContent)
Das Objekt pContent wird an die Schlange angehängt. Falls pContent gleich null ist, bleibt die Schlange unverändert.

    
Auftrag
void dequeue()
Das erste Objekt wird aus der Schlange entfernt. Falls die Schlange leer ist, wird sie nicht verändert.

    
Anfrage
ContentType front()
Die Anfrage liefert das erste Objekt der Schlange. Die Schlange bleibt unverändert. Falls die Schlange leer ist, wird null zurückgegeben.

    
Zum Vergleich: Stack<ContentType>

    
boolean isEmpty() · void push(ContentType pContent) · void pop() · ContentType top()
LIFO: push legt oben ab, pop entfernt das oberste Objekt, top liefert es.
